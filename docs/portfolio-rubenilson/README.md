# Portfólio de Rubenilson Júnior

Portfólio pessoal de Rubenilson dos Santos Júnior, estudante de Análise e Desenvolvimento de Sistemas com interesse em desenvolvimento web e backend.

## Sobre o projeto

Site estático criado para apresentar minha trajetória, tecnologias em estudo, experiência em TI e projetos. A interface inclui navegação responsiva, terminal visual, animações de entrada e formas de contato.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Fonts: Inter e JetBrains Mono

## Estrutura

```text
.
├── index.html
├── script.js
└── styles.css
```

## Como visualizar

Abra `index.html` em um navegador. O projeto não precisa de dependências ou etapa de build.
