# Proposta do projeto: Conhecimento +50

## 1) Descrição do app

O Conhecimento +50 é uma plataforma digital que conecta pessoas com mais de 50 anos para compartilhar experiências, aprender com a vivência de outras gerações e fortalecer redes de apoio, orientação e colaboração.

A ideia central é transformar conhecimento prático em conexão humana. A plataforma permite que usuários publiquem saberes, ofereçam mentorias, busquem ajuda em temas específicos e encontrem pessoas com afinidade profissional, cultural ou de vida.

O app valoriza a experiência como capital social. Em vez de uma rede focada apenas em networking profissional, ele cria um espaço de trocas reais entre pessoas que têm histórias, habilidades e percepção de mundo para compartilhar.

## 3) Texto para README

# Conhecimento +50

Plataforma de troca de conhecimento e conexão para pessoas com 50 anos ou mais.

## Visão

O Conhecimento +50 nasceu para conectar experiências, saberes e oportunidades entre pessoas maduras que desejam continuar aprendendo, compartilhando e colaborando. A proposta é criar uma comunidade acolhedora, inspiradora e útil, onde a vivência de cada pessoa vira valor para o próximo.

## O que a plataforma oferece

- Cadastro de perfis com interesses, experiências e áreas de conhecimento
- Publicação de conhecimentos, dicas e especialidades
- Busca por pessoas com afinidade ou expertise
- Conexões entre usuários para troca de mentorias e aprendizados
- Espaço para aprender com a experiência de outras gerações
- Ambiente digital para fortalecer redes sociais e profissionais

## Público-alvo

- Pessoas acima de 50 anos
- Profissionais em transição de carreira
- Aposentados e aposentadas que querem seguir ativos
- Mentores, conselheiros e especialistas em vivência
- Pessoas que valorizam troca de saberes e relacionamento humano

## Objetivo

Criar um ambiente de colaboração em que a experiência acumulada seja reconhecida, compartilhada e reutilizada para gerar aprendizado, conexão e impacto positivo.

## Tecnologias

- React + Vite para o frontend
- Java Spring Boot para o backend
- JWT para autenticação
- PostgreSQL como banco principal
- Node.js/Express para serviços e prototipagem local

## Como executar localmente

1. Instale as dependências do frontend:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

2. Inicie o backend Java:
   ```bash
   cd backend
   ./mvnw spring-boot:run
   ```

3. Acesse a aplicação no navegador:
   ```text
   http://localhost:5173
   ```

## Ideia central

A experiência é um ativo. O Conhecimento +50 transforma sabedoria em conexão, e conexão em aprendizado contínuo.
